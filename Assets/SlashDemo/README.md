# 霜庭 · 2.5D 斜视近战原型

适用于本项目 Unity 6000.6.7f1、URP 2D 和已启用的 Input System。主角默认使用八方向手绘的白发白袍剑客；可连续旋转的立体网格原型保留为可选外观，敌人仍使用几何占位素材，场地为手绘私人庄园。

## Tab 属性界面

按 Tab 可在任意位置打开不透明的属性面板，默认选中顶部「功法」页；点击「功法 / 属性 / 物品」切换页面。「功法」只显示当前角色正在修习的功法及其境界招式与主动技能，内容超出时可滚动；「属性」「物品」当前仅实现切页按钮，内容区留空。再次按 Tab、按 Esc 或点击关闭可返回游戏。打开期间暂停移动与战斗，关闭后沿用按键释放保护。

茶桌旁 F 打开独立的原版「功法图鉴」界面，左侧列出全部已登记功法，供查看与切换；没有属性 / 物品页签。图鉴与属性面板各自保存浏览状态并互斥，F / Esc 关闭图鉴，Tab / Esc 关闭属性面板。

现在可在图鉴左侧选择《流云剑诀》或《玄铁剑罡》，再点击「修习此功法」。角色只能修习一本：被动、层数和 Q 均随装备切换；切换会中断动作并清空旧功法层数、剑罡护体、剑气和剑痕，两本的 Q 冷却分别保留。选择保存在 `SlashDemo.EquippedTechnique`，重新运行会自动载入；返回家园 / 重新开始保留所选功法，境界仍按原规则重置为练气。Tab 功法页只展示当前修习的一本，换书须回书桌。

## 玄铁剑罡

定位重击 / 蓄力，核心决策为松手时机。右键蓄力按进度积累 0–6 层罡气，松手必定释放，包括尚未拔完剑的 0 层；释放后罡气清空。练气时空格取消蓄力；筑基起蓄力中冲刺会按当前进度立即释放重击。只有修习《玄铁剑罡》才获得提前释放与以下效果，《流云剑诀》的原有重击规则继续沿用。

## 功法与洞府图鉴

主角默认修习《流云剑诀》，主连段，意在“以快打慢，连而不绝”。功法条目与境界说明集中登记在 `CultivationTechnique.cs` 的 `TechniqueCatalog`，图鉴自动列出已登记的功法。洞府主厅茶桌碰撞边缘 1.35 米内，在屏幕中央显示“F查看功法图鉴”；按 F 打开，F / Esc 或关闭按钮返回。阅读时暂停模拟并屏蔽战斗输入，关闭后等待攻击 / Q / F 等按键松开；外出地图不出现桌边交互。

境界效果逐级累积：

- 练气「一式·叠浪」：每次普攻命中后叠一层，每层使普攻伤害提升 8%，最多五层；恰好五层时额外提升 20%，默认五层合计增伤 60%（基础伤害 × 1.60）。额外加成与逐层加成相加，层数降到四层及以下即移除额外 20%；调试将层数上限改低时，未达到五层不获得额外加成。该次伤害按命中前已有层数结算，新层数用于后续普攻，多目标命中不重复叠层。持续 2 秒，普攻首次命中刷新完整计时，满层后仍刷新。普通连招的 0.65 秒重置只重置段数；暂停冻结倒计时。成功闪避扣除两层叠浪，最低为零，剩余层数保留原到期时间及对应增伤 / 攻速；闪避不会刷新持续时间，未成功释放的闪避不扣层。普攻未命中不叠层、不刷新计时，已有层数延续上一次命中的剩余时间；受击和重击仍清空叠浪；传送和境界切换保留原有清空逻辑。旋风斩和按普攻伤害结算的剑潮沿用该增伤；Q 消耗叠浪，其沿途伤害及额外斩击保留原有独立数值。
- 筑基「二式·起风」：每层叠浪额外增加 5% 普攻攻速，默认最多五层 / 25%，筑基及以上境界生效。共用叠浪层数和持续时间，清空 / 过期 / Q 消耗时一并移除。普攻出手时按已有层数快照增伤与攻速，动作和第三段后的收招间隔按攻速倍率缩短，不修改保存的基础时长。第四段旋风斩也属于普攻，使用攻速加成，其扩散判定仍按原有环形效果时序完成。重击、Q 及其末端斩击保持原有速度。F1 → 功法可调整攻速并查看当前加成。

## 打开试玩

1. 在 Unity 中打开 `Assets/SlashDemo/Scenes/SlashArena.unity`，或使用菜单 `Tools > Slash Demo > Open Arena`。

4. 如需敌人波次挑战，在进入 Play 前取消 `SlashArena` 的 `Practice Mode`，然后走进右侧训练场。

游戏界面保留血量、冲刺冷却和 F1 调试面板，木桩头顶显示血量数字。命中时显示伤害数字，向上飘动并在 0.65 秒内淡出；玩家受伤数字为红色。开场训练场指引、模式 / 波次 / 地点、操作说明、连招 / 蓄力状态和旧失败菜单已移除；Esc 打开暂停菜单 / 继续，R 重来和 T 切换模式快捷键已取消。

Buff 数据集中由 `SlashPlayer.CollectBuffs` 收集，`CombatBuffBar` 以稳定 ID 去重并维护有序列表，`BuffBarLayout` 独占坐标分配。格子间隔 8，按血条的 282 宽度每行排列 5 个，第 6 个自动换行；移除后紧凑排列。同一 Buff 更新层数只修改原项，未来新增 Buff 只需在收集入口注册数据，不为每种 Buff 手写坐标。图标按资源路径缓存，效果说明由当前功法参数生成；悬停提示在移开鼠标或 Buff 消失时隐藏，并限制在画面范围内。数据与布局定义随 `SlashHUD` 保存在同一脚本中。

已有场景会在 Play 时自动应用斜视表现，无需重新挂组件或重建场景。若想在编辑状态下查看完整布局，可使用原有 `Tools > Slash Demo > Rebuild Arena` 生成场景，再观察 Game 视图；Scene 的 2D 编辑视图仍适合编辑 XY 地面和碰撞。

清晰度：URP 渲染比例设为 1.25（宽高各提高 25%，再缩回输出尺寸），并启用 4× MSAA。人物图集保持原尺寸、无压缩和双线性过滤。编辑器在本场景每次会话首次载入 / Play 时自动关闭 Game 视图的低分辨率预览，并适配预览尺寸，避免把低分辨率画面额外放大；也可手动运行 `Tools > Slash Demo > Improve Game View Clarity`。此调整会增加渲染开销，输出窗口尺寸和镜头范围保持原设置。Game 窗口很小时，实际可显示的人物细节仍受窗口像素数限制。

Game 视图调整使用其原有属性设置和缩放方法，同时更新高 DPI 下的渲染尺寸与鼠标映射；已通过本机 Unity 6000.6.7f1 程序集接口校验。实现参考 [Unity GameView 源码](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/GameView/GameView.cs)和 [URP 渲染资源说明](https://docs.unity.com/en-us/engine/6000.0/manual/render-pipelines/universal-render-pipeline/urp-reference/universalrp-asset)。本次 C# 编译通过，实际 Play 渲染尚未验证。

## 运行时调参

点击 Play 并让 Game 窗口获得焦点后，按 **F1** 或点击右侧按钮展开面板。面板自动接入现有场景，无需挂载组件或重新生成庭院。

- **角色**：移动速度、冲刺速度 / 时长 / 冷却、连招衔接窗口、最大气血和调试无敌。
- **连招**：三段固定为前方劈砍 / 反向劈砍 / 大范围劈砍，可分别调整伤害、距离、挥剑幅度、剑刃判定宽度、总时长、起手占比、发力占比和击退。出招不再自动前踏。
- **敌人**：移速倍率、血量倍率、伤害、预警时间、攻击距离、木桩血量。
- **反馈**：命中停顿倍率、镜头震动倍率、刀光拖尾时长（0.10–0.14 秒，默认 0.12 秒）、外晕宽度（0.05–0.18，默认 0.10）、月牙收尖指数（0.4–1.0，默认 0.7）、命中镜头推近幅度（0–0.08，默认 0.04）和音效音量。推近设为 0 可关闭；收尖指数越大，中段越集中。反馈参数可保存，旧存档自动补齐默认值。
- **视角**：俯角、角色视觉比例和镜头放大，边试玩边调整。
- **重击**：蓄力时长、释放后摇、剑气宽度、飞行距离、飞行速度、伤害和击退。默认分别为 0.8 秒、0.25 秒、3.4、6、15.5、55 和 8；宽度、距离和速度使用地面世界单位。

拖动滑条或点击两侧的 − / + 可即时调节。鼠标位于面板上，或拖动滑条至面板外时，会屏蔽角色移动、瞄准、冲刺与新攻击输入；已出手的攻击仍会完成。敌人会继续活动，需要安静调参时可按 Esc 暂停，面板在暂停状态也能操作。

本次调整会保留到程序重置当前模式及后续波次。修改最大血量会保留当前血量比例，不复活已死亡单位。敌人倍率始终以该波基础属性计算，不会反复叠乘；红色攻击预警会跟随敌人攻击距离缩放。

动作参数从下一次出手生效，当前已经开始的动作会保持原来的参数，避免剑刃轨迹与判定突然跳变。起手和发力占比之外的时间用于收招，至少保留 15% 的收招时间。旧 v1 / v2 存档自动迁移为两次前方劈砍与一次大范围劈砍，取消前踏，并将旧第三段的距离、幅度、时长和判定宽度至少提升到新默认值；其余合法调参值保留。新保存使用 v3，旧存档不删除。

重击规则：右键按下开始蓄力，期间可用鼠标调整朝向；满蓄仅给出提示，持续按住不会自动发射。提前松手直接取消。满蓄松手后锁定朝向，先停顿 0.033 秒，再横扫 0.17 秒，然后进入面板设定的释放后摇。扫至进度 0.55、剑刃正对前方时发射剑气，约在松手后 0.127 秒。蓄力、停顿、横扫与后摇都阻止 WASD / 方向键移动和普攻，空格可立即打断；在发射前打断不会补发剑气，在发射后打断则已出手剑气继续飞行。打断后继续按住右键不会重新蓄力，需要松开后再次按下。

剑气为大半径圆上的 60° 浅弧，圆弧朝飞行方向凸出，两端渐细收尖，保留冰蓝外光与白色刃线。半径等于面板设定的剑气宽度，宽度按两端之间的直线距离计算；调宽时整体弧形按比例放大。圆弧中心的最前点从角色前方 0.4 单位处出现，按设定距离飞行后消失，可穿透多个敌人，每道剑气对同一敌人只造成一次伤害。渲染与命中共用 32 段圆弧，每帧检测弧线移动扫过的区域，避免低帧率漏击，弧线后方的空白区域不会被整体填成攻击范围；剑气宽度独立于飞行距离。蓄力开始时记录本次参数，调参不会改变当前蓄力、后摇或已飞出的剑气。暂停、切出游戏或操作调参面板会取消未释放的蓄力；暂停冻结已释放剑气与后摇，重来和角色死亡清理剑气。旧存档自动补齐重击默认值，原有调参值保留。

**保存参数**：使用本项目的 PlayerPrefs 本地保存，下次运行自动载入。**载入保存**：恢复上次手动保存的参数。**恢复默认**：恢复场景启动时的参数，不删除旧存档；若希望下次也使用默认值，请再点击「保存参数」。未保存的修改在停止 Play 后丢弃。

## 编辑场景和调整手感

想在编辑状态下看到完整庭院：使用 `Tools > Slash Demo > Rebuild Arena`。这会将同一套庭院生成并保存在示例场景中，之后可直接编辑场景对象。此菜单会覆盖本示例场景和占位贴图，先保存需要保留的自定义修改。

生成后的 `Actors/Player - Swordsman` 上有 `SlashPlayer`：可以调整移动速度、冲刺速度 / 时长 / 冷却、生命值，以及每一段的伤害、距离、挥剑幅度、时长、阶段比例、判定宽度和击退。三段动作顺序由调参校验固定，旧的前踏字段只用于兼容读取，不再驱动位移。

运行时生成的敌人使用 `SlashEnemy`；波次数量和敌人属性成长位于 `SlashArena.SpawnWave()`。主角素材与衣袖连接位于 `HeroAppearance`，敌人占位视觉位于 `DemoArt.Character()`；可分别替换，保留现有战斗逻辑。

## 脚本分工

- `SlashArena`：场地生成、模式、波次和重置。
- `SlashPlayer`：移动、冲刺、连斩、右键蓄力及释放后摇和伤害判定。
- `HeroAppearance` / `HeroFacingMath`：八方向图集切片、靴底支点、带迟滞的投影方向选择、肩部接口、衣袖与冰蓝长剑。
- `HeroArmMath`：肘部绕开躯干的弯曲姿态，以及剑、上臂、前臂、手掌与身体的分层遮挡。
- `HeroWalkMesh` / `HeroGaitMath` / `HeroLayerMath`：三个身体子网格、按位移推进的步相、躯干转动与头部补偿、衣摆随动、静止恢复。
- `SwordMotion`：前方劈砍 / 反向劈砍 / 大范围劈砍的剑姿、握柄与剑尖位置，以及与视觉共用的剑刃扫掠检测。
- `SlashEnemy`：敌人行为与受击。
- `SlashEffects` / `SlashCamera`：剑气飞行与命中、命中反馈、音效和镜头。
- `ObliqueProjection` / `ObliqueView`：斜视投影、鼠标射线换算、角色显示高度与视角参数。
- `ObliqueActor` / `ObliqueScenery`：站立角色、贴地阴影、脚下遮挡排序，以及围墙 / 灯座的立体顶面和立面。
- `CombatInputBuffer` / `ChargedAttackState` / `CombatFeedbackMath`：顿帧期间的输入缓存、蓄力与后摇时钟、震屏数学、逐点拖尾衰减与连续倾斜投影。
- `SlashHUD` / `DemoInput` / `DemoArt`：界面、输入和占位视觉。
- `SlashTuningPanel` / `SlashTuningSettings`：运行时面板、参数校验和本地保存。
- `Editor/SlashDemoTools`：生成 / 打开场景，以及批处理检查入口。
- `SlashSmokeTest`：仅编辑器编译的场景集成检查。

# 霜庭 · 2.5D 斜视近战原型

适用于本项目 Unity 6000.6.7f1、URP 2D 和已启用的 Input System。主角默认使用八方向手绘的白发白袍剑客；可连续旋转的立体网格原型保留为可选外观，敌人和场地仍使用几何占位素材。

## 可选 360° 立体角色原型

`Hero360Model` 用封闭的立体网格构造身体、面部、白色高马尾、衣袍、双臂、靴子、冰蓝剑和银边蓝剑鞘。模型随鼠标方向连续旋转，没有八方向取整或切换图集；肩膀属于同一套旋转后的立体结构，右手保持主手身份。当前为程序生成的细化原型：收窄脸型并刻画下颌、细眉眼和鼻唇，将刘海与长马尾拆分为有弯曲和收尖的发束；白色长外袍改为前方敞开的分片衣摆，带实际厚度、蓝色内衬和褶皱，增加交领、银色腰封、玉坠流苏、喇叭袖、靴沿和剑鞘银饰。衣料、银带和头发通过局部 UV 引用原 `WhiteSwordsmanAtlas` 的衣褶 / 绣纹明暗，纹理透明度仅控制细节混合，不裁切立体网格。

主场景与脚本默认值均已切回八方向手绘人物，停止当前 Play 后重新进入即可载入。在 Player 的 `SlashPlayer > Character appearance > Use Continuous 3D` 勾选，可在下一次 Play 使用立体原型。无需重建场景，也无需导入外部模型。

动作继续使用原 `SwordMotion`：前两段水平普攻右手单持、左手自然下垂；第三段和重击双手握剑，沿用普攻 50% 减速、0.1 秒整套后摇及冲刺取消。起手 / 发力的腰部转动、重心下压、行走踏步、衣摆与马尾跟随都作用于立体结构；头脸保持整体比例。待机收剑、拔剑及出鞘后隐藏剑鞘保留，原剑鞘贴图仍供八方向模式使用。3D 刀身蓄满亮度提升至 1.8 倍，汇聚光点、刀光和 Bloom 沿用现有实现；冲刺残影复制当前网格姿态，并在取消、重来时清理其独立网格和材质。

`Hero360Toon` 通过 URP 2D 的 `Universal2D` Pass 绘制带法线和分层明暗的真实网格。角色自身三角形按当前视角从后到前排列，保留原场景的脚下深度排序，不向共用深度缓冲写入角色深度。原型采用每帧 CPU 关节变形和三角形排序，适合当前单主角验证；批量三维角色需要后续改为专门的三维渲染 / 骨骼方案。

验证：运行时与编辑器脚本编译通过；`Verification/RunChecklistChecks.ps1 -Suite Hero360Checks` 的 227143 项检查通过，包含头脸、双层外袍分片、袖形、逐束头发和基础几何的有限顶点、索引、向外绕序、单位法线、正体积、局部 UV 范围及整圈连续转向。另有 74405 项动力链、894 项单手姿态、652 项佩剑、5509 项重击和 17 项 Bloom 配置检查通过。尝试启动 Unity 后台执行原生检查时，编辑器在载入检查方法前以代码 1 退出（`Temp/Hero360Native.log`），未生成截图，因此实际 Shader 导入与 Play 画面仍未验证。

正常编辑器内可运行 `Tools > Slash Demo > Validate 360 Hero`：检查实际动态网格与整圈朝向，导出四方向 OBJ 到 `Temp/Hero360-*.obj`，有图形设备时另绘制 PNG 到 `Temp/Hero360-*.png`，通过后输出 `HERO360_NATIVE_PASS`，不会重建或保存现有场景。原 `Validate Hero Appearance` 仍可验证旧素材，运行中也能识别当前 360° 模型。

## 八方向俯视手绘人物（默认）

主角保留银白高马尾、白色绣纹外袍、浅蓝内衫、玉饰与流苏、白靴和冰蓝长剑。当前素材位于 `Resources/SlashDemo/WhiteSwordsmanDirections-v5.png`（2048×1280，真实透明通道）。v5 使用内置 imagegen，以修好的 v4 正面为参考统一八方向的白袍剪裁、蓝色内衫、银色腰封、白靴和肩部衣料，八个方向均可辨认双脚。4×2 图集按下、右下、右、右上、上、左上、左、左下排列，每格 512×640；可见人物高度统一至约 560 像素，脚底与水平支点对齐，并保留透明间隔，避免切片混入邻格人物。v2、v3、v4 原图及 `WhiteSwordsmanAtlas.png` 保留，后者用于独立衣袖、长剑和素材缺失时的兼容回退。生成提示词、装配及验证说明见 `ArtNotes/WhiteSwordsmanDirections-v5.md`。

已有场景会在 Play 时自动替换主角，无需重建场景；停止当前 Play 后重新运行即可载入。鼠标方向经当前俯角投影后选择对应视角，不再用两张正背面图左右镜像代替侧面；转向有 5° 迟滞区，避免边界抖动。各视角从可见靴底提取脚下支点并统一人物高度，减少转身时脚底跳动。

画面参考《暖雪》《墨境》的俯视手绘观感：能看到头顶、肩部与靴面，以冷色暗部、亮色衣褶和轮廓线表现体积。`HeroCloth` 在原画明暗之上增加轻微冷色体积阴影和内轮廓。公开资料不足以确认《暖雪》的内部角色动画管线；本项目使用自己的程序网格和双臂骨架，不依赖 Spine，也未导入其他游戏的素材。

人物网格分为下摆与腿部、躯干、头部三个子网格；行走由实际位移驱动下肢，攻击时以网格剪切、重心下压和分部位相位表现拧腰，衣摆和头发继承躯干变形后再延迟跟随。独立双臂继续连接变形后的肩部与握剑点；v5 对八个方向分别标定布料上的左右肩连接点，包含侧身与斜前视角的偏移。三段劈砍、普攻减速 50%、冲刺打断以及冰蓝刀光保持现有逻辑。这里是多方向 2.5D 手绘角色，尚非可自由旋转的三维人物或完整逐帧动作库。

肩部衔接：动态上臂使用原衣袖中央 56% 的连续白色布料，避开两端画出的空心袖口；袖根向肩膀内侧重叠 `0.08 × 角色比例`，覆盖手臂旋转时的接缝。前臂、手掌和背面遮挡保持原有分层方式。素材生成提示词和修改说明见 `ArtNotes/WhiteSwordsmanDirections-v3.md`。

当前腰间佩剑：`CarryLength=0.72`、参考屏幕角度 `CarryAngle=-122°`，按八方向角色的右胯位置选择左右倾斜，并经俯角反投影，让剑鞘始终斜向身侧下方。仅保留剑鞘长度与佩挂方向的调整，其余手臂材质、手掌、握点、剑显隐及拔收剑时序恢复原有实现。

持剑位置微调：持剑平面保持角色比例的 0.84，位于腰部；所有剑姿沿角色前方增加 0.17 的握点间距，待机握点从 `(0.22,-0.06)` 调整为 `(0.39,-0.06)`，比上一版再向前 0.05，让双手位于腹部前方而非身体中心。剑身、刀光与命中轨迹共用该位置。背面与斜背面视角将手掌和前臂排到身体后面，使其被躯干自然遮挡；上臂保持可见，肘部向身体两侧并略向下弯曲，保留肩侧衣袖轮廓。遮挡依据带迟滞的实际人物视角切换，不会仅因鼠标越过一个方向阈值而整组隐藏手臂。

当前工作区的程序步态参数为 `StrideDistance=0.44`、`CycleDistance=1.6/0.9≈1.7778`、`StanceFraction=0.60`、抬脚高度 `0.110`，身体起伏系数为 `0.012`。代码清理保留了这些现值及原有移动速度。`HeroWalkMesh` 沿用八方向髋 / 膝 / 踝标定、分离腿部网格、刚性靴子和衣摆下裤腿补面；网格为 40×56 的三个副本，加 16 个补面顶点，保留三个身体子网格。步相按实际位移推进，暂停 / 顿帧及冲刺冻结踏步，停步平滑恢复站姿。衣料着色器继续使用腿部遮罩与 `_WalkBlend`。原有八方向 v5 人物素材和攻击变形保持现有设置。

代码清理移除了不再绘制的旧双层线条刀光创建和重复控制、未被使用的状态接口，以及只写不读的脚步接地标记。旧场景中的线条刀光仍会在初始化时关闭一次；当前网格刀光、存档转换、素材回退与可选 3D 模式保留。运行时和编辑器编译、9 组纯逻辑 / 几何回归检查及 17 项 Bloom 配置检查通过；实际 Unity Play 画面未在本次清理中验证。

`HeroAppearance` 在 Unity 内切片图集，并按视角肩部位置连接手臂。两张贴图都需保留 **Read/Write Enabled**、**Non Power of 2: None** 和透明通道；随附 `.meta` 已配置。若八方向素材缺失，会回退到原正背面主角。想放大查看细节可在 F1「视角」调整镜头放大或角色比例。

外观未变化的问题已修复：首版图集 `.meta` 的末尾空值与文件结束格式使 Unity YAML 导入失败，素材因此被忽略；同时项目关闭了 Play 时的域重载，首次失败还会被静态缓存保留。新版元数据使用明确的空字符串并保留末尾换行；外观缓存每次 Play 重置，失败不再永久缓存。

编辑器重新编译后，`HeroAssetImport` 自动检查新旧图集导入、八个独立视角、脚底支点、三个身体子网格、旧身体 / 剑的隐藏、衣袖替换，以及剑尖与判定长度对齐。成功时 Console 显示 `SLASH_HERO_IMPORT_OK`。也可手动运行 `Tools > Slash Demo > Validate Hero Appearance`；运行中检查成功则显示 `SLASH_HERO_LIVE_OK`。该检查不重建或保存场景，不要求修改项目的域重载设置。

行走导入检查还验证衣袍 Shader、实际网格腿部位移、上半身稳定、UV 不动、顿帧 / 冲刺不推进步相，以及停步恢复；通过后显示 `SLASH_HERO_WALK_OK`。

行走导致无法行动的问题已修复：Unity 禁止在已有 `SpriteRenderer` 的对象上添加 `MeshFilter`，首版行走组件因此在 `SlashPlayer.Awake` 中抛出异常，中断生命值与武器初始化。行走网格现位于独立的 `Walking mesh` 子对象；外观初始化异常会恢复静态角色，不中断玩家控制。编辑器检查新增了组件分离与异常回退验证。若当前 Play 会话已因旧版异常初始化失败，停止后重新 Play 即可重新创建角色，无需重建场景。

## 打开试玩

1. 在 Unity 中打开 `Assets/SlashDemo/Scenes/SlashArena.unity`，或使用菜单 `Tools > Slash Demo > Open Arena`。
2. 点击 Play，再点击 Game 窗口，让游戏获得键鼠焦点。
3. 初始为三个木桩的练习模式。场地和角色会在 Play 时生成；尚未运行时场景中只有 `Slash Arena` 根对象，属于预期行为。
4. 按 T 进入敌人波次挑战。

## 2.5D 斜上方视角

默认使用 **45° 正交斜视**：地面纵深压缩，角色面向镜头站立，脚下阴影贴在地面上。围墙和灯座增加了顶面与立面，角色与场景按脚下位置处理前后遮挡。

已有场景会在 Play 时自动应用斜视表现，无需重新挂组件或重建场景。若想在编辑状态下查看完整布局，可使用原有 `Tools > Slash Demo > Rebuild Arena` 生成场景，再观察 Game 视图；Scene 的 2D 编辑视图仍适合编辑 XY 地面和碰撞。

在 **F1 → 视角** 可调整相对地面的俯角（30–65°）、角色视觉比例（1.0–1.6）和镜头放大（0.85–1.25）。角度越小，地面纵深压缩越明显；默认角色比例为 1.25。视角参数支持保存，旧调参存档会补齐这些默认值。

清晰度：URP 渲染比例设为 1.25（宽高各提高 25%，再缩回输出尺寸），并启用 4× MSAA。人物图集保持原尺寸、无压缩和双线性过滤。编辑器在本场景每次会话首次载入 / Play 时自动关闭 Game 视图的低分辨率预览，并适配预览尺寸，避免把低分辨率画面额外放大；也可手动运行 `Tools > Slash Demo > Improve Game View Clarity`。此调整会增加渲染开销，输出窗口尺寸和镜头范围保持原设置。Game 窗口很小时，实际可显示的人物细节仍受窗口像素数限制。

Game 视图调整使用其原有属性设置和缩放方法，同时更新高 DPI 下的渲染尺寸与鼠标映射；已通过本机 Unity 6000.6.7f1 程序集接口校验。实现参考 [Unity GameView 源码](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/GameView/GameView.cs)和 [URP 渲染资源说明](https://docs.unity.com/en-us/engine/6000.0/manual/render-pipelines/universal-render-pipeline/urp-reference/universalrp-asset)。本次 C# 编译通过，实际 Play 渲染尚未验证。

移动、敌人追击和碰撞保持在原来的地面坐标中。斜向移动按屏幕方向换算，鼠标通过挥剑高度平面的射线换算瞄准，剑刃和拖尾显示在同一高度；调整视角与角色大小不会修改攻击距离或碰撞半径。震屏沿相机的屏幕平面输出，保留此前的冲击幅度和顿帧输入缓存。

## 运行时调参

点击 Play 并让 Game 窗口获得焦点后，按 **F1** 或点击右侧按钮展开面板。面板自动接入现有场景，无需挂载组件或重新生成庭院。

- **角色**：移动速度、冲刺速度 / 时长 / 冷却、连招衔接窗口、最大气血和调试无敌。
- **连招**：三段固定为前方劈砍 / 反向劈砍 / 大范围劈砍，可分别调整伤害、距离、挥剑幅度、剑刃判定宽度、总时长、起手占比、发力占比和击退。出招不再自动前踏。
- **敌人**：移速倍率、血量倍率、伤害、预警时间、攻击距离、木桩血量。
- **反馈**：命中停顿倍率、镜头震动倍率、刀光拖尾时长（0.10–0.14 秒，默认 0.12 秒）、外晕宽度（0.05–0.18，默认 0.10）、月牙收尖指数（0.4–1.0，默认 0.7）、命中镜头推近幅度（0–0.08，默认 0.04）和音效音量。推近设为 0 可关闭；收尖指数越大，中段越集中。反馈参数可保存，旧存档自动补齐默认值。
- **视角**：俯角、角色视觉比例和镜头放大，边试玩边调整。
- **重击**：蓄力时长、释放后摇、剑气宽度、飞行距离、飞行速度、伤害和击退。默认分别为 0.8 秒、0.25 秒、1.8、6、12、55 和 8；宽度、距离和速度使用地面世界单位。

拖动滑条或点击两侧的 − / + 可即时调节。鼠标位于面板上，或拖动滑条至面板外时，会屏蔽角色移动、瞄准、冲刺与新攻击输入；已出手的攻击仍会完成。敌人会继续活动，需要安静调参时可按 Esc 暂停，面板在暂停状态也能操作。

本次调整会保留到 R 重来、T 切换模式及后续波次。修改最大血量会保留当前血量比例，不复活已死亡单位。敌人倍率始终以该波基础属性计算，不会反复叠乘；红色攻击预警会跟随敌人攻击距离缩放。

动作参数从下一次出手生效，当前已经开始的动作会保持原来的参数，避免剑刃轨迹与判定突然跳变。起手和发力占比之外的时间用于收招，至少保留 15% 的收招时间。旧 v1 / v2 存档自动迁移为两次前方劈砍与一次大范围劈砍，取消前踏，并将旧第三段的距离、幅度、时长和判定宽度至少提升到新默认值；其余合法调参值保留。新保存使用 v3，旧存档不删除。

重击规则：右键按下开始蓄力，期间可用鼠标调整朝向；满蓄仅给出提示，持续按住不会自动发射。提前松手直接取消。满蓄松手后锁定朝向，先停顿 0.033 秒，再横扫 0.17 秒，然后进入面板设定的释放后摇。扫至进度 0.55、剑刃正对前方时发射剑气，约在松手后 0.127 秒。蓄力、停顿、横扫与后摇都阻止 WASD / 方向键移动和普攻，空格可立即打断；在发射前打断不会补发剑气，在发射后打断则已出手剑气继续飞行。打断后继续按住右键不会重新蓄力，需要松开后再次按下。

剑气为大半径圆上的 60° 浅弧，圆弧朝飞行方向凸出，两端渐细收尖，保留冰蓝外光与白色刃线。半径等于面板设定的剑气宽度，宽度按两端之间的直线距离计算；调宽时整体弧形按比例放大。圆弧中心的最前点从角色前方 0.4 单位处出现，按设定距离飞行后消失，可穿透多个敌人，每道剑气对同一敌人只造成一次伤害。渲染与命中共用 32 段圆弧，每帧检测弧线移动扫过的区域，避免低帧率漏击，弧线后方的空白区域不会被整体填成攻击范围；剑气宽度独立于飞行距离。蓄力开始时记录本次参数，调参不会改变当前蓄力、后摇或已飞出的剑气。暂停、切出游戏或操作调参面板会取消未释放的蓄力；暂停冻结已释放剑气与后摇，重来和角色死亡清理剑气。旧存档自动补齐重击默认值，原有调参值保留。

**保存参数**：使用本项目的 PlayerPrefs 本地保存，下次运行自动载入。**载入保存**：恢复上次手动保存的参数。**恢复默认**：恢复场景启动时的参数，不删除旧存档；若希望下次也使用默认值，请再点击「保存参数」。未保存的修改在停止 Play 后丢弃。

## 脚本分工

- `SlashArena`：场地生成、模式、波次和重置。
- `SlashPlayer`：移动、冲刺、连斩、右键蓄力及释放后摇和伤害判定。

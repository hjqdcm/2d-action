# 被击败后在洞府复活

角色受到致命伤害后，暂停战斗并显示居中的战败面板，按钮文案为「在洞府中复活」。战败界面优先于暂停菜单、传送选择与功法页面显示，普通继续按钮不能绕过复活。

点击按钮返回洞府出生点，按当前最大气血恢复满血；境界恢复练气，功法恢复初始流云剑诀，并更新功法保存选择，避免下次运行重新带回死亡前的功法。角色外观模式和战斗统计沿用现有设置。只重建被击败的角色，避免保留倒地模型及旧攻击状态；恢复相机跟随，卸载外出地图及毒池等区域特效。输入等待按钮松开后恢复，避免一次复活点击同时触发普攻。存活时重复调用复活不会创建新角色。

物品保留规则：除非用户以后特别指明，复活时所有物品均不保留。当前没有实际背包、物品持有或掉落数据，物品页面为空；后续新增物品系统必须在死亡复活时清空，不能默认继承旧角色的持有物。

实现：`SlashArena.PlayerDied`、`SlashArena.ReviveAtHome` 与 `SlashHUD.DrawDefeatPanel`。

Unity 6000.6.7f1 临时项目验证入口：`SlashDemo.Editor.RevivalValidation.RunBatch`。验证覆盖洞府和山野的真实致命伤害、实际面板按钮点击、调参后 137 最大气血的满血复活、功法和境界重置、保存选择同步、统计保留、相机和地图清理、重复点击保护、输入恢复及再次攻击。测试会还原运行前的功法选择存档。

新规则验证结果：`Logs/Revival-v2.log` 包含 `REVIVAL_PASS`，38 项检查通过，退出码 0；运行时代码编译通过。
